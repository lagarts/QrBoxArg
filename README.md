# QrBoxArg

**QR BOX ARG** — Escaneá. Encontrá. Organizá.

Plataforma comercial argentina para generar, administrar y utilizar etiquetas físicas con códigos QR únicos.

## Stack

- [Next.js](https://nextjs.org) + TypeScript
- Tailwind CSS
- [Supabase](https://supabase.com) (PostgreSQL + Auth + Storage + RLS)
- [Vercel](https://vercel.com) (hosting)
- PWA instalable

## Estado

En desarrollo por fases. Ver `SEGUIMIENTO-PROYECTO.md` para arquitectura, modelo de datos y plan de fases.
